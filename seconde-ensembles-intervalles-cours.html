Les ensembles de nombres

ℕ — Entiers naturels
ℕ = {0 ; 1 ; 2 ; 3 ; …} — Les nombres utilisés pour compter.
ℤ — Entiers relatifs
ℤ = {… ; −2 ; −1 ; 0 ; 1 ; 2 ; …} — Les entiers naturels et leurs opposés.
𝔻 — Nombres décimaux
𝔻 = { a10n | a ∈ ℤ, n ∈ ℕ } — Exemples : 0,5 ; −3,14 ; 7
ℚ — Nombres rationnels
ℚ = { pq | p ∈ ℤ, q ∈ ℤ* } — Tout nombre pouvant s'écrire comme fraction. Exemples : 13 ; −74 ; 2
ℝ — Nombres réels
L'ensemble de tous les nombres, rationnels et irrationnels. Ils remplissent entièrement la droite graduée.
ℕ ⊂ ℤ ⊂ 𝔻 ⊂ ℚ ⊂ ℝ

Les nombres irrationnels

Un nombre irrationnel est un réel qui n'est pas rationnel : il ne peut pas s'écrire sous forme de fraction.

Exemples : √2 ≈ 1,41421… ; π ≈ 3,14159… ; √3 ; √5

Leur écriture décimale est infinie et non périodique.

Preuve que √2 est irrationnel

Raisonnement par l'absurde.

Supposons √2 = pq avec p, q entiers, q ≠ 0, fraction irréductible.

Alors 2 = p²q², donc p² = 2q².

Ainsi p² est pair, donc p est pair. Posons p = 2k.

Alors 4k² = 2q², soit q² = 2k², donc q est aussi pair.

Contradiction : p et q seraient tous deux pairs, la fraction ne serait pas irréductible. ∎

Les intervalles de ℝ

Un intervalle est une partie de ℝ constituée de tous les réels compris entre deux bornes.

[a ; b]a ≤ x ≤ bFermé borné
]a ; b[a < x < bOuvert borné
[a ; b[a ≤ x < bSemi-ouvert borné
]a ; b]a < x ≤ bSemi-ouvert borné

[a ; +∞[x ≥ aFermé non borné

Convention : Les crochets tournés vers l'extérieur (]) signifient que la borne est exclue. Ceux tournés vers l'intérieur ([) signifient qu'elle est incluse.

L'infini (−∞ ou +∞) est toujours accompagné d'un crochet ouvert.

Représentation sur la droite graduée

Intersection et réunion d'intervalles

Intersection A ∩ B
L'ensemble des réels qui appartiennent à A et à B simultanément.
Réunion A ∪ B
L'ensemble des réels qui appartiennent à A ou à B (ou aux deux).

Valeur absolue et distance

Définition
La valeur absolue d'un réel x, notée |x|, est la distance de x à 0 sur la droite graduée.
|x| = x si x ≥ 0, et |x| = −x si x < 0.
Distance entre deux réels
La distance entre a et b sur la droite graduée est |a − b| = |b − a|.
|x − a| < r  ⟺  a − r < x < a + r  ⟺  x ∈ ]a − r ; a + r[
|x − a| ≤ r  ⟺  a − r ≤ x ≤ a + r  ⟺  x ∈ [a − r ; a + r]

Exercices

Exercice 1 — Appartenance aux ensembles

Pour chaque nombre, indiquer le plus petit ensemble auquel il appartient parmi ℕ, ℤ, 𝔻, ℚ, ℝ \ ℚ :

a) 7    b) −3    c) 0,25    d) 13    e) √5    f) π

Voir la correction

a) 7 ∈ ℕ   b) −3 ∈ ℤ   c) 0,25 = 25100 ∈ 𝔻   d) 13 ∈ ℚ (non décimal)   e) √5 ∈ ℝ \ ℚ   f) π ∈ ℝ \ ℚ

Exercice 2 — Écriture d'intervalles

Écrire sous forme d'intervalle :

a) L'ensemble des réels x tels que −2 ≤ x < 5

b) L'ensemble des réels x tels que x > 3

c) L'ensemble des réels x tels que x ≤ −1

Voir la correction

a) [−2 ; 5[   b) ]3 ; +∞[   c) ]−∞ ; −1]

Exercice 3 — Intersection et réunion

Soient A = [−3 ; 4] et B = [1 ; 7]. Déterminer :

a) A ∩ B    b) A ∪ B

Voir la correction

a) A ∩ B = [1 ; 4] (les réels qui sont dans les deux intervalles)

b) A ∪ B = [−3 ; 7] (les réels qui sont dans au moins un des deux)

Exercice 4 — Valeur absolue

Résoudre les inéquations suivantes et donner la solution sous forme d'intervalle :

a) |x − 3| ≤ 2    b) |x + 1| < 4    c) |2x − 6| ≤ 10

Voir la correction

a) |x − 3| ≤ 2 ⟺ 1 ≤ x ≤ 5 ⟺ x ∈ [1 ; 5]

b) |x + 1| < 4 ⟺ |x − (−1)| < 4 ⟺ −5 < x < 3 ⟺ x ∈ ]−5 ; 3[

c) |2x − 6| ≤ 10 ⟺ |2(x − 3)| ≤ 10 ⟺ |x − 3| ≤ 5 ⟺ −2 ≤ x ≤ 8 ⟺ x ∈ [−2 ; 8]

Exercice 5 — Problème de synthèse

On considère les ensembles : A = ]−∞ ; 3], B = [−1 ; +∞[, C = ]0 ; 5[.

a) Déterminer A ∩ B    b) Déterminer A ∩ C    c) Déterminer (A ∩ B) ∪ C

d) Montrer que 73 appartient à A ∩ C mais pas à ℤ.

Voir la correction

a) A ∩ B = [−1 ; 3] (les x tels que x ≤ 3 et x ≥ −1)

b) A ∩ C = ]0 ; 3] (les x tels que x ≤ 3 et 0 < x < 5)

c) (A ∩ B) ∪ C = [−1 ; 3] ∪ ]0 ; 5[ = [−1 ; 5[

d) 73 ≈ 2,33… Donc 0 < 73 < 3, soit 73 ∈ ]0 ; 3] = A ∩ C. De plus, 73 n'est pas entier, donc 73 ∉ ℤ.
