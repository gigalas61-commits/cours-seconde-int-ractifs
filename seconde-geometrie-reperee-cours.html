1. Repère du plan

Définition

Un repère du plan est constitué d'un point O appelé origine et de deux axes perpendiculaires gradués :

  • L'axe des abscisses (horizontal, noté x)
  • L'axe des ordonnées (vertical, noté y)

Lorsque les deux axes ont la même unité de longueur et sont perpendiculaires, on parle de repère orthonormé (O ; I ; J).

Coordonnées d'un point

Tout point M du plan est repéré par un couple unique (xM ; yM) :

  • xM est l'abscisse de M
  • yM est l'ordonnée de M
Notation M(xM ; yM) — par exemple A(3 ; 2) ou B(−1 ; 4)
Astuce : Pour lire les coordonnées d'un point, on projette orthogonalement ce point sur chacun des axes.

2. Distance entre deux points

Théorème

Dans un repère orthonormé, la distance entre deux points A(xA ; yA) et B(xB ; yB) est :

Formule de la distance AB = (xB − xA)² + (yB − yA)²

Démonstration (idée)

Cette formule découle directement du théorème de Pythagore. En traçant le triangle rectangle dont l'hypoténuse est [AB], les cotés de l'angle droit mesurent |xB − xA| et |yB − yA|.

Exemple

Soient A(1 ; 3) et B(4 ; 7).

AB = (4−1)² + (7−3)² = 9 + 16 = 25 = 5

Remarque : L'ordre des points n'a pas d'importance : AB = BA. En effet, (−a)² = a².

3. Milieu d'un segment

Définition et formule

Le milieu M d'un segment [AB] est le point qui est à égale distance de A et de B.

Si A(xA ; yA) et B(xB ; yB), alors les coordonnées du milieu M sont :

Coordonnées du milieu M ( xA + xB2 ; yA + yB2 )

Exemple

Soient A(2 ; 5) et B(6 ; 1).

xM = 2 + 62 = 4   yM = 5 + 12 = 3

Donc M(4 ; 3).

Retenir : Le milieu, c'est la moyenne des coordonnées !

Glissez les points A (rouge) ou B (bleu). Le milieu M est en vert.

4. Équation de droite

Forme réduite

Toute droite non verticale admet une équation de la forme :

Équation réduite y = mx + p
  • m est le coefficient directeur (ou pente). Il mesure l'inclinaison de la droite.
  • p est l'ordonnée à l'origine. C'est l'ordonnée du point d'intersection avec l'axe des ordonnées.
Coefficient directeur m = yB − yAxB − xA   (avec xA ≠ xB)

Cas particuliers

  • Si m = 0, la droite est horizontale : y = p
  • Si la droite est verticale, son équation est x = k (pas de forme y = mx + p)
  • Si m > 0, la droite est croissante
  • Si m < 0, la droite est décroissante
Méthode : Pour trouver l'équation d'une droite passant par A et B, on calcule d'abord m, puis on détermine p en remplaçant les coordonnées d'un point dans y = mx + p.

5. Droites parallèles et sécantes

Propriétés

Soient d1 : y = m1x + p1 et d2 : y = m2x + p2 deux droites non verticales.

Droites parallèles d1 ∥ d2 ⇔ m1 = m2
  • Si m1 = m2 et p1 = p2, les droites sont confondues.
  • Si m1 = m2 et p1 ≠ p2, les droites sont strictement parallèles (pas de point commun).
  • Si m1 ≠ m2, les droites sont sécantes en un unique point.
Point d'intersection Si m1 ≠ m2, on résout m1x + p1 = m2x + p2 ⇒ x = p2 − p1m1 − m2
Attention : Deux droites verticales distinctes (x = a et x = b avec a ≠ b) sont aussi parallèles !

6. Exercices

Exercice 1 — Lecture de coordonnées

Dans un repère orthonormé, placer les points A(3 ; 2), B(−1 ; 4), C(−3 ; −2) et D(2 ; −3). Quels points se trouvent dans le deuxième quadrant ?

Voir la correction

Le deuxième quadrant correspond aux points dont l'abscisse est négative et l'ordonnée positive.

Parmi les points donnés :

  • A(3 ; 2) : x > 0 et y > 0 → 1er quadrant
  • B(−1 ; 4) : x < 0 et y > 0 → 2e quadrant
  • C(−3 ; −2) : x < 0 et y < 0 → 3e quadrant
  • D(2 ; −3) : x > 0 et y < 0 → 4e quadrant

Seul B est dans le 2e quadrant.

Exercice 2 — Calcul de distances

Calculer les distances suivantes :

  1. A(1 ; 2) et B(4 ; 6)
  2. C(−2 ; 3) et D(1 ; −1)
  3. E(0 ; 0) et F(5 ; 12)
Voir la correction

1. AB = (4−1)² + (6−2)² = 9 + 16 = 25 = 5

2. CD = (1−(−2))² + (−1−3)² = 9 + 16 = 25 = 5

3. EF = 25 + 144 = 169 = 13

Exercice 3 — Triangle isocèle

Soient A(1 ; 1), B(5 ; 1) et C(3 ; 4). Le triangle ABC est-il isocèle ?

Voir la correction

Calculons les longueurs des trois côtés :

AB = (5−1)² + (1−1)² = 16 = 4

AC = (3−1)² + (4−1)² = 4 + 9 = 13

BC = (3−5)² + (4−1)² = 4 + 9 = 13

On a AC = BC = √13, donc le triangle ABC est isocèle en C.

Exercice 4 — Coordonnées du milieu

Calculer les coordonnées du milieu M du segment [AB] dans chaque cas :

  1. A(2 ; 6) et B(8 ; 2)
  2. A(−3 ; 5) et B(7 ; −1)
Voir la correction

1. xM = (2+8)/2 = 5   yM = (6+2)/2 = 4   donc M(5 ; 4)

2. xM = (−3+7)/2 = 2   yM = (5+(−1))/2 = 2   donc M(2 ; 2)

Exercice 5 — Équation de droite

Déterminer l'équation réduite de la droite passant par A(1 ; 3) et B(3 ; 7).

Voir la correction

Étape 1 : Calcul du coefficient directeur.

m = (7 − 3) / (3 − 1) = 4 / 2 = 2

Étape 2 : Détermination de p.

On utilise le point A(1 ; 3) : 3 = 2 × 1 + p ⇒ p = 1

L'équation est : y = 2x + 1

Vérification avec B : 2 × 3 + 1 = 7 ✓

Exercice 6 — Intersection de droites

Soient d1 : y = 2x + 1 et d2 : y = −x + 7. Déterminer les coordonnées de leur point d'intersection.

Voir la correction

Les droites sont sécantes car m1 = 2 ≠ m2 = −1.

Résolution :

2x + 1 = −x + 7

3x = 6

x = 2

y = 2 × 2 + 1 = 5

Le point d'intersection est I(2 ; 5).

Vérification dans d2 : −2 + 7 = 5 ✓
