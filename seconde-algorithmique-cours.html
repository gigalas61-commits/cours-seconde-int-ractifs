1. Variables et types de données

Qu’est-ce qu’une variable ?

Une variable est un nom qui désigne un emplacement en mémoire où l’on stocke une valeur. En Python, on affecte une valeur à une variable avec le signe =.

# Affectation de variables age = 16 nom = "Alice" taille = 1.68 est_eleve = True
Les 4 types fondamentaux :
• int — entier : 42, -3, 0
• float — décimal : 3.14, -0.5
• str — chaîne de caractères : "Bonjour", 'Python'
• bool — booléen : True ou False

La fonction type()

Pour connaître le type d’une valeur ou d’une variable, on utilise type().

print(type(42)) # <class 'int'> print(type(3.14)) # <class 'float'> print(type("hello")) # <class 'str'> print(type(True)) # <class 'bool'>

Conversions de types

On peut convertir un type en un autre avec les fonctions int(), float(), str(), bool().

x = "25" # x est un str y = int(x) # y vaut 25 (int) z = float(x) # z vaut 25.0 (float) w = str(42) # w vaut "42" (str)

2. Instructions conditionnelles

La structure if / elif / else

Les instructions conditionnelles permettent d’exécuter du code uniquement si une condition est vraie.

age = 16 if age >= 18: print("Majeur") elif age >= 16: print("Presque majeur") else: print("Mineur")
Opérateurs de comparaison :
== égal  |  != différent  |  < inférieur  |  > supérieur  |  <= inférieur ou égal  |  >= supérieur ou égal
Opérateurs logiques :
and — ET logique  |  or — OU logique  |  not — NÉGATION

Conditions combinées

note = 14 bonus = True if note >= 12 and bonus: print("Admis avec mention") elif note >= 10 or bonus: print("Admis") else: print("Refusé")

Conditions imbriquées

x = 15 if x > 0: if x % 2 == 0: print("Positif et pair") else: print("Positif et impair") else: print("Négatif ou nul")
En Python, l’indentation (4 espaces) est obligatoire pour délimiter les blocs de code. Pas d’accolades comme en JavaScript ou en C !

3. Boucles

La boucle for

La boucle for répète un bloc d’instructions un nombre défini de fois.

# Afficher les nombres de 0 à 4 for i in range(5): print(i) # Affiche : 0, 1, 2, 3, 4
range() :
• range(n) → 0, 1, 2, ..., n-1
• range(a, b) → a, a+1, ..., b-1
• range(a, b, pas) → a, a+pas, a+2*pas, ... (tant que < b)

La boucle while

La boucle while répète tant qu’une condition est vraie.

# Compter de 1 à 5 compteur = 1 while compteur <= 5: print(compteur) compteur = compteur + 1

Accumulateur dans une boucle

Un pattern très fréquent : accumuler un résultat au fil des itérations.

# Somme des entiers de 1 à 100 somme = 0 for i in range(1, 101): somme = somme + i print(somme) # 5050
Attention aux boucles infinies avec while ! Assurez-vous que la condition finira par devenir False.

4. Fonctions

Définir une fonction

Une fonction est un bloc de code réutilisable. On la définit avec def et elle renvoie un résultat avec return.

def aire_rectangle(largeur, hauteur): """Calcule l'aire d'un rectangle.""" return largeur * hauteur # Appel de la fonction resultat = aire_rectangle(5, 3) print(resultat) # 15
Syntaxe d’une fonction :
def nom_fonction(param1, param2, ...):
    # corps de la fonction
    return valeur_de_retour

Fonction sans return (procédure)

Une fonction sans return ne renvoie rien (renvoie None implicitement).

def saluer(prenom): print("Bonjour", prenom, "!") saluer("Alice") # Affiche : Bonjour Alice !

Portée des variables

Les variables créées à l’intérieur d’une fonction sont locales : elles n’existent pas en dehors.

def doubler(n): resultat = n * 2 # resultat est locale return resultat print(doubler(7)) # 14 # print(resultat) # ERREUR ! resultat n'existe pas ici

Exemples de fonctions utiles

def est_pair(n): return n % 2 == 0 def valeur_absolue(x): if x >= 0: return x else: return -x def factorielle(n): res = 1 for i in range(1, n + 1): res = res * i return res

5. Listes

Création et accès

Une liste est une collection ordonnée d’éléments, délimitée par des crochets.

fruits = ["pomme", "banane", "cerise"] print(fruits[0]) # "pomme" (premier élément) print(fruits[2]) # "cerise" (troisième élément) print(fruits[-1]) # "cerise" (dernier élément)
À retenir : les indices commencent à 0. Une liste de n éléments a des indices de 0 à n-1.

Parcourir une liste

notes = [12, 15, 8, 17, 14] # Parcours par élément for note in notes: print(note) # Parcours par indice for i in range(len(notes)): print("Note", i, ":", notes[i])

Construire une liste avec une boucle

# Liste des carrés de 0 à 9 carres = [] for i in range(10): carres.append(i ** 2) print(carres) # [0, 1, 4, 9, 16, 25, 36, 49, 64, 81]
Pour calculer la moyenne d’une liste de nombres : sum(L) / len(L). La fonction sum() calcule la somme des éléments.

2 Conditions

Écrire une fonction mention(note) qui renvoie la mention selon la note :

  • note ≥ 14 → "Bien"
  • note ≥ 12 → "Assez bien"

4 Fonctions

Écrire une fonction est_premier(n) qui renvoie True si n est un nombre premier, False sinon.

Rappel : un nombre premier n’est divisible que par 1 et lui-même (n ≥ 2).

Voir la correction
def est_premier(n): if n < 2: return False for i in range(2, n): if n % i == 0: return False return True
