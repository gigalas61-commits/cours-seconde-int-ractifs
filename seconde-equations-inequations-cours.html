Seconde

Équations et inéquations du 1er degré

Cours interactif — Programme de Seconde générale

1. Équations du premier degré

Définition

Une équation du premier degré à une inconnue x est une équation qui peut se ramener à la forme :

ax + b = 0    avec a ≠ 0

Où a et b sont des nombres réels donnés, et x est l’inconnue.

Résoudre une équation, c’est trouver toutes les valeurs de x qui la vérifient.

Propriétés fondamentales

On peut transformer une équation sans changer ses solutions en appliquant les règles suivantes :

  • Addition/Soustraction : On peut ajouter (ou soustraire) un même nombre aux deux membres.
  • Multiplication/Division : On peut multiplier (ou diviser) les deux membres par un même nombre non nul.
On « fait passer » un terme d’un membre à l’autre en changeant son signe.

Résolution de ax + b = 0

ax + b = 0  ⇒  ax = −b  ⇒  x = −ba
Exemple 1 : Résoudre 3x − 7 = 0
3x = 7  ⇒  x = 73
L’ensemble des solutions est S = {73}.
Exemple 2 : Résoudre 5x + 2 = 3x − 6
5x − 3x = −6 − 2  ⇒  2x = −8  ⇒  x = −4
S = {−4}.

Visualisation interactive : la balance

Déplacez le curseur pour résoudre l’équation pas à pas. La balance s’équilibre quand les deux membres sont égaux.

2. Équations produit et quotient

Règle du produit nul

A × B = 0  ⇔  A = 0  ou  B = 0

Un produit de facteurs est nul si et seulement si au moins un des facteurs est nul.

Exemple détaillé

Résoudre : (2x − 4)(3x + 9) = 0

D’après la règle du produit nul :
• 2x − 4 = 0  ⇒  2x = 4  ⇒  x = 2
• 3x + 9 = 0  ⇒  3x = −9  ⇒  x = −3

S = {−3 ; 2}

Règle du quotient nul

AB = 0  ⇔  A = 0  et  B ≠ 0

Un quotient est nul si et seulement si le numérateur est nul et le dénominateur est non nul.

Toujours vérifier que la valeur trouvée n’annule pas le dénominateur !

Exemple détaillé

Résoudre : 4x − 122x + 6 = 0

Condition d’existence : 2x + 6 ≠ 0  ⇒  x ≠ −3

Numérateur nul : 4x − 12 = 0  ⇒  x = 3

Vérification : pour x = 3, le dénominateur vaut 2(3) + 6 = 12 ≠ 0.  ✓
S = {3}

Exemple avec valeur interdite

Résoudre : x + 5x + 5 = 0

Condition : x + 5 ≠ 0  ⇒  x ≠ −5
Numérateur nul : x + 5 = 0  ⇒  x = −5
Or x = −5 est une valeur interdite.
S = ∅ (aucune solution)

Méthode générale

  1. Déterminer les valeurs interdites (dénominateur ≠ 0).
  2. Résoudre l’équation du numérateur = 0.
  3. Vérifier que chaque solution trouvée n’est pas une valeur interdite.
  4. Conclure en donnant l’ensemble des solutions.

3. Inéquations du premier degré

Définition

Une inéquation est une inégalité comportant une inconnue. Résoudre une inéquation, c’est trouver toutes les valeurs de x qui la vérifient.

L’ensemble des solutions s’exprime sous forme d’intervalle.

Règles de manipulation

  • On peut ajouter ou soustraire un même nombre aux deux membres sans changer le sens de l’inégalité.
  • On peut multiplier ou diviser par un nombre strictement positif sans changer le sens.
  • On change le sens de l’inégalité quand on multiplie ou divise par un nombre strictement négatif.
Règle capitale : Multiplier ou diviser par un nombre négatif ⇒ inverser le sens de l’inégalité

Exemples

Exemple 1 : Résoudre 3x − 6 > 0
3x > 6  ⇒  x > 2
S = ]2 ; +∞[
Exemple 2 : Résoudre −2x + 8 ≤ 0
−2x ≤ −8
On divise par −2, on change le sens :
x ≥ 4
S = [4 ; +∞[
Exemple 3 : Résoudre 5x + 1 < 2x − 8
3x < −9  ⇒  x < −3
S = ]−∞ ; −3[

Rappel : notation des intervalles

x > a ]a ; +∞[
x ≥ a [a ; +∞[
x < a ]−∞ ; a[
x ≤ a ]−∞ ; a]

Visualisation : droite graduée

Choisissez le type d’inéquation et la borne pour visualiser l’intervalle solution sur la droite des réels.

4. Systèmes de deux équations à deux inconnues

Définition

Un système de deux équations à deux inconnues (x, y) se présente sous la forme :

a1x + b1y = c1
a2x + b2y = c2

Résoudre ce système, c’est trouver le couple (x ; y) qui vérifie les deux équations simultanément.

Méthode par substitution

  1. Exprimer une inconnue en fonction de l’autre à partir d’une des équations.
  2. Remplacer dans l’autre équation pour obtenir une équation à une seule inconnue.
  3. Résoudre cette équation, puis déduire la seconde inconnue.
Exemple :
x + 2y = 7   (1)
3x − y = 7   (2)

De (1) : x = 7 − 2y
Dans (2) : 3(7 − 2y) − y = 7
21 − 6y − y = 7  ⇒  −7y = −14  ⇒  y = 2
Donc x = 7 − 2(2) = 3
S = {(3 ; 2)}

Méthode par combinaison (addition)

  1. Multiplier les équations pour obtenir des coefficients opposés pour une inconnue.
  2. Additionner les deux équations pour éliminer cette inconnue.
  3. Résoudre, puis déduire la seconde inconnue.
Exemple :
2x + 3y = 12   (1)
4x − 3y = 6    (2)

(1) + (2) : 6x = 18  ⇒  x = 3
Dans (1) : 6 + 3y = 12  ⇒  y = 2
S = {(3 ; 2)}

Visualisation : intersection de droites

Modifiez les coefficients pour voir l’intersection des deux droites correspondant au système.

5. Résolution graphique

Principe

Graphiquement, résoudre l’équation f(x) = k revient à chercher les abscisses des points d’intersection de la courbe y = f(x) avec la droite horizontale y = k.

Résoudre f(x) > k revient à chercher les intervalles où la courbe est au-dessus de la droite y = k.

Méthode

  1. Tracer la courbe de f et la droite y = k.
  2. Repérer les points d’intersection (solutions de f(x) = k).
  3. Lire les zones où la courbe est au-dessus ou en dessous de la droite.

Visualisation interactive

Déplacez la droite horizontale y = k pour lire graphiquement les solutions. Choisissez la fonction à étudier.

6. Exercices

Exercice 1 — Équation simple

Résoudre l’équation : 4x − 10 = 2x + 6

Voir la correction
4x − 10 = 2x + 6
4x − 2x = 6 + 10
2x = 16
x = 8

S = {8}

Vérification : 4(8) − 10 = 22 et 2(8) + 6 = 22.  ✓

Exercice 2 — Équation avec fractions

Résoudre : 3x + 12 = x − 54

Voir la correction
On multiplie les deux membres par 4 :
2(3x + 1) = x − 5
6x + 2 = x − 5
5x = −7
x = −75 = −1,4

S = {−1,4}

Exercice 3 — Équation produit

Résoudre : (5x − 15)(x + 7) = 0

Voir la correction
Un produit est nul si et seulement si l’un des facteurs est nul.

• 5x − 15 = 0  ⇒  5x = 15  ⇒  x = 3
• x + 7 = 0  ⇒  x = −7

S = {−7 ; 3}

Exercice 4 — Inéquation

Résoudre : −3x + 12 ≥ 0

Voir la correction
−3x + 12 ≥ 0
−3x ≥ −12
On divise par −3 (négatif) : on change le sens
x ≤ 4

S = ]−∞ ; 4]

Exercice 5 — Équation quotient

Résoudre : 6x − 18x − 1 = 0

Voir la correction
Condition : x − 1 ≠ 0, donc x ≠ 1

Numérateur nul : 6x − 18 = 0  ⇒  x = 3
Vérification : 3 ≠ 1  ✓

S = {3}

Exercice 6 — Système

Résoudre le système :
2x + y = 10
x − 3y = −11

Voir la correction
Méthode par substitution :
De la 1ère équation : y = 10 − 2x
Dans la 2nde : x − 3(10 − 2x) = −11
x − 30 + 6x = −11
7x = 19
x = 197
y = 10 − 387 = 327

S = {(197 ; 327)}

Vérification :
2 × 197 + 327 = 38 + 327 = 707 = 10  ✓
