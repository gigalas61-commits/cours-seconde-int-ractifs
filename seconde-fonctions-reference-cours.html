La fonction carré

Définition

La fonction carré est définie sur ℝ par f(x) = x².

Ensemble de définition : Df = ℝ

Propriétés

  • Parité : f est paire car f(−x) = (−x)² = x² = f(x) pour tout x ∈ ℝ. Sa courbe est symétrique par rapport à l'axe des ordonnées.
  • Signe : f(x) ≥ 0 pour tout x ∈ ℝ, et f(x) = 0 ⇔ x = 0.
  • Images remarquables : f(0) = 0, f(1) = 1, f(−1) = 1, f(2) = 4, f(−3) = 9.

Variations

La fonction carré est :

  • décroissante sur ]−∞ ; 0]
  • croissante sur [0 ; +∞[

Le minimum est atteint en x = 0 avec f(0) = 0.

La fonction inverse

Définition

La fonction inverse est définie sur ℝ* par f(x) = 1x.

Ensemble de définition : Df = ℝ* = ]−∞ ; 0[ ∪ ]0 ; +∞[

Propriétés

  • Parité : f est impaire car f(−x) = 1−x = −1x = −f(x). La courbe admet l'origine comme centre de symétrie.
  • Signe : f(x) est du même signe que x.
  • Asymptotes : l'axe des abscisses (y = 0) est asymptote horizontale ; l'axe des ordonnées (x = 0) est asymptote verticale.

Variations

La fonction inverse est strictement décroissante sur chacun des intervalles ]−∞ ; 0[ et ]0 ; +∞[.

Attention : on ne peut pas dire qu'elle est décroissante sur ℝ* car cet ensemble n'est pas un intervalle.

La fonction racine carrée

Définition

La fonction racine carrée est définie sur [0 ; +∞[ par f(x) = √x.

Ensemble de définition : Df = [0 ; +∞[

Propriétés

  • Signe : f(x) ≥ 0 pour tout x ≥ 0.
  • Images remarquables : f(0) = 0, f(1) = 1, f(4) = 2, f(9) = 3.
  • Relation clé : √x = y ⇔ x = y² (avec x ≥ 0 et y ≥ 0).
  • La fonction racine carrée est la réciproque de la fonction carrée restreinte à [0 ; +∞[.

Variations

La fonction racine carrée est strictement croissante sur [0 ; +∞[.

La fonction cube

Définition

La fonction valeur absolue

Définition

La fonction valeur absolue est définie sur ℝ par f(x) = |x|.

On a : |x| = x si x ≥ 0, et |x| = −x si x < 0.

Ensemble de définition : Df = ℝ

Propriétés

  • Parité : f est paire car f(−x) = |−x| = |x| = f(x). La courbe est symétrique par rapport à l'axe des ordonnées.
  • Signe : f(x) ≥ 0 pour tout x ∈ ℝ, et f(x) = 0 ⇔ x = 0.
  • Interprétation : |x| représente la distance de x à 0 sur la droite des réels. Plus généralement, |a − b| est la distance entre a et b.

Variations

  • Décroissante sur ]−∞ ; 0]
  • Croissante sur [0 ; +∞[

Minimum en x = 0 : f(0) = 0.

x−∞0+∞
f(x)=|x|+∞↘0↗+∞

Comparaison des fonctions de référence

Positions relatives

  • Sur [0 ; 1] : x² ≤ x ≤ √x (la parabole est sous la droite y = x, elle-même sous la racine).
  • Sur [1 ; +∞[ : √x ≤ x ≤ x² (les positions s'inversent après 1).
  • Au point x = 1, toutes ces fonctions coïncident : f(1) = 1.

Exercices

Exercice 1 — Images et antécédents

1. Calculer f(−3), f(0), f(5) pour f(x) = x².

2. Déterminer les antécédents de 16 par la fonction carré.

3. Le nombre −9 a-t-il un antécédent par la fonction carré ? Justifier.

1. f(−3) = (−3)² = 9 ; f(0) = 0 ; f(5) = 25.

2. On cherche x tel que x² = 16, donc x = 4 ou x = −4. Les antécédents de 16 sont 4 et −4.

3. Non. Pour tout x ∈ ℝ, x² ≥ 0, donc x² ne peut pas être égal à −9. Le nombre −9 n'a pas d'antécédent.

Exercice 2 — Comparaison sans calculatrice

Sans calculatrice, comparer les nombres suivants :

1. (−7)² et (−5)²

2. √3 et √7

3. 13 et 15

1. On a −7 < −5 < 0. La fonction carré est décroissante sur ]−∞ ; 0], donc elle inverse l'ordre : (−7)² > (−5)², soit 49 > 25.

2. On a 3 < 7 et les deux nombres sont positifs. La fonction racine carrée est croissante sur [0;+∞[, donc √3 < √7.

3. On a 3 < 5 et les deux nombres sont strictement positifs. La fonction inverse est décroissante sur ]0;+∞[, donc 13 > 15.

Exercice 3 — Résolution d'équations

Résoudre dans ℝ :

1. x² = 49

2. x³ = −8

3. √x = 5

4. |x| = 3

1. x² = 49 ⇔ x = 7 ou x = −7. S = {−7 ; 7}.

2. x³ = −8 ⇔ x = −2 (la fonction cube est strictement croissante, solution unique). S = {−2}.

3. Condition : x ≥ 0. √x = 5 ⇔ x = 25. S = {25}.

4. |x| = 3 ⇔ x = 3 ou x = −3. S = {−3 ; 3}.

Exercice 4 — Inéquations

Résoudre :

1. x² ≤ 9

2. 1x > 2 (pour x > 0)

1. x² ≤ 9 ⇔ x² − 9 ≤ 0 ⇔ (x − 3)(x + 3) ≤ 0. Par un tableau de signes, S = [−3 ; 3].

2. Pour x > 0 : 1x > 2 ⇔ 1x − 2 > 0 ⇔ 1 − 2xx > 0. Puisque x > 0, le dénominateur est positif, donc on cherche 1 − 2x > 0, soit x < 12. S = ]0 ; 12[.

Exercice 5 — Problème de synthèse

On considère les fonctions f(x) = x² et g(x) = 2x + 3.

1. Résoudre f(x) = g(x). Interpréter graphiquement.

2. Résoudre f(x) < g(x). Interpréter graphiquement.

1. x² = 2x + 3 ⇔ x² − 2x − 3 = 0. Δ = 4 + 12 = 16. x1 = 2 − 42 = −1 et x2 = 2 + 42 = 3. Les courbes se coupent en (−1 ; 1) et (3 ; 9).

2. x² < 2x + 3 ⇔ x² − 2x − 3 < 0 ⇔ (x + 1)(x − 3) < 0. Par le tableau de signes : S = ]−1 ; 3[. La parabole est sous la droite entre les deux points d'intersection.
